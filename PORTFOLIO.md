# Portfolio Overview: Agent Ledger

Agent Ledger is a workflow-governance product for teams that want automation to move work forward without losing approvals, ownership, budgets, or audit history. It is strongest as a portfolio project for operations, product operations, implementation, AI operations, and workflow automation roles.

## What this project proves

- Can turn a broad operational risk into a concrete product workflow.
- Can design approval queues, budgets, permissions, owners, and audit logs around real business constraints.
- Can explain AI-assisted work in a practical way without pretending automation should run unmanaged.
- Can build a large Next.js/TypeScript app with clear product surfaces and reviewable boundaries.
- Can separate implemented features from planned scope, which matters in honest portfolio review.

## Reviewer path

1. Read the "Recruiter quick read" section in [README.md](README.md).
2. Review the screenshots and demo flow.
3. Open the approvals, agent setup, and repository/data files linked from the README.
4. Run `npm run lint`, `npm run typecheck`, and `npm run build` if reviewing locally.

## Role fit

Agent Ledger is not meant to position Jesse for cybersecurity jobs or senior engineering jobs. It is meant to show practical judgment around workflow design, operational controls, documentation, and the business side of automation.

The clearest job connection is any role where someone needs to coordinate tools, policies, stakeholders, records, and follow-up without losing track of what happened.
