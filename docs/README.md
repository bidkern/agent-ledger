# Agent Ledger Docs

Use this folder as the operating system for the venture.

## Start here

- `customer-implementation-guide.md`: customer-facing setup, safe testing, REST/MCP connection, and FAQ
- `venture-thesis.md`: market choice, product wedge, pricing, and acquisition logic
- `90-day-plan.md`: detailed launch timeline and milestones
- `go-to-market.md`: outbound motion, ICP, pilot design, and pipeline math
- `security-architecture.md`: security rules and architecture constraints
- `business-ops.md`: company setup, tooling, hiring, and KPI cadence
- `production-checklist.md`: deployment notes, envs, and this-week launch gate

## Working principle

The business is intentionally designed to start as a high-trust, service-backed AI product.
That lets us move fast on revenue without pretending the product is fully autonomous before it earns that right.
