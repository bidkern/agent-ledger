# Agent Ledger Docs

Use this folder as the reviewer path for the portfolio project.

## Start here

- `customer-implementation-guide.md`: customer-facing setup, safe testing, REST/MCP connection, and FAQ
- `security-architecture.md`: security rules and architecture constraints
- `production-checklist.md`: deployment notes, envs, and launch-readiness checks
- `screenshots/`: current product proof images
- `demo-videos/`: short walkthrough clips

## Working principle

The project is strongest when it reads as practical workflow software: clear permissions, reviewable actions, useful logs, and sober boundaries around automation.
